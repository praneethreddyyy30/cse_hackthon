Enterprise System Design

How a production short-form recommendation engine scales using Event Sourcing, Vector Embeddings, and Agentic RAG Filters.

Stage 1
Streaming Event Ingestion
Every user interaction on the mobile application creates low-latency event telemetry capturing watch ratio, loops, explicit likes, bookmarks, and sharing signals.
Stage 2
Dynamic Profiling Vector
Events are pushed through a mathematical weight compiler to establish an multi-dimensional interest vector. A missing semicolon joke maps to low-level syntax debugging, but paired with interview vlogs, the vectors immediately shift towards algorithmic career growth.
Stage 3
Candidate Retrieval
Using cosine similarity calculations, the user's computed interest vectors query a database containing thousands of curated educational videos. Only candidates with high semantic overlap are retrieved for final ranking.
Stage 4
Agent Reasoning & Guardrails
The final candidate pool passes through a Gemini-powered Agent. The agent performs semantic analysis, writes an explanation connecting the recommendation to the student's history, checks difficulty scores, and filters out clickbait and marketing hype.
